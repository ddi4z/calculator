# Assignment: Full-Stack Calculator Application

## Objective

Build a full-stack calculator application with a React frontend and a backend microservice. The frontend should consume the backend API to perform basic and advanced arithmetic operations.

Focus on:
- clean design
- maintainable code
- testable architecture

## Requirements

### Functional requirements

#### Calculator operations
- Addition
- Subtraction
- Multiplication
- Division
- Optional advanced operations:
  - Exponentiation
  - Square root
  - Percentage

#### Frontend requirements (React)
- Intuitive UI for entering input and displaying results
- Input validation and error handling
- Responsive design with basic mobile support

#### Backend requirements (REST API)
- Expose endpoints for calculator operations
- Validate input and handle edge cases
- Handle errors such as:
  - division by zero
  - invalid data
- Return results in JSON format

### Non-functional requirements
- Clean, readable, and idiomatic code in both frontend and backend
- Unit tests covering key functionality for both layers
- Documentation including:
  - setup instructions
  - API usage
  - design rationale
- Optional: Dockerfile for full-stack deployment

## Constraints

### Frontend
- Use React
- TypeScript is preferred

### Backend
- Go is preferred

## Deliverables

- Git repository containing frontend and backend code
- README with:
  - setup instructions
  - API examples
  - design decisions
- Unit tests and coverage report
- Optional: Dockerfile to run frontend and backend together

## Instructions

- Use any AI tooling you would like
- Spend approximately 2–4 hours on this assignment
- Prioritize correctness, clarity, and maintainability over extra features
- Push your solution to GitHub, GitLab, or another Git repository
- Share the repository link with us for evaluation
- Share any prompts used during the work

## README requirements

Your README must include:
- Setup instructions
- How to run the frontend and backend
- Examples of API calls (if using REST)
- Design decisions or assumptions
